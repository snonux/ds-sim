ds-sim
======

DS-Sim is an open source simulator programmed in Java for distributed systems. DS-Sim stands for "Verteilte Systeme Simulator," which is the German translation for "Distributed Systems Simulator."

![Screenshot](screenshots/vs-ss1.jpg "DS-Sim")

DS-Sim is a fork of VS-Sim: https://codeberg.org/snonux/vs-sim/
